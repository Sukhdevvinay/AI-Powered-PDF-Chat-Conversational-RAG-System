# AI-Powered PDF Chat & Conversational RAG System

A full-stack conversational document intelligence application for querying PDF documents using retrieval-augmented generation (RAG).

## Planned stack

- React
- Node.js / Express
- Pinecone vector database
- OpenAI-compatible LLM and embeddings APIs
- PDF text extraction, chunking, and semantic retrieval

## Status

Project scaffold under active development.
